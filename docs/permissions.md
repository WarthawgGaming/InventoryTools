# Permissions

| Permission | Description |
|---|---|
| `inventorytools.use` | Base permission |
| `inventorytools.sort.asc` | Allows ascending sorting |
| `inventorytools.sort.desc` | Allows descending sorting |
| `inventorytools.condense` | Allows stack condensing |

---

## LuckPerms Example

```text
/lp group default permission set inventorytools.use true
```
